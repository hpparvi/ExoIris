Installation
============

Install ExoIris either from PyPI as::

    pip install exoiris

or clone it from GitHub and install as::

   git clone https://github.com/hpparvi/ExoIris
   cd ExoIris
   pip install .

ExoIris requires Python 3.10 or later, `PyTransit <https://github.com/hpparvi/PyTransit>`_ 2.9.2 or later, and
`LDTk <https://github.com/hpparvi/ldtk>`_ 1.9.3 or later. The dependencies are installed automatically by ``pip``.
